\section{System Overview and Problem Formulation}
\subsection{System Architecture}
The proposed system forms a closed-loop perception, geometric modeling and control pipeline, as illustrated in Fig.~\ref{fig:overview}. The input consists of RGB-D images captured above the conveyor. \revadd{The instance segmentation module} \reviewnote{\mbox{Reviewer 1, Q2}} first segments baggage instances and suppresses tag-like visual interference. \revadd{The spatio-temporal geometric modeling module} \reviewnote{\mbox{Reviewer 1, Q2}} projects the selected mask into a point cloud, removes residual 3D outliers, and estimates a temporally stable OBB. \revadd{The motion planning module} \reviewnote{\mbox{Reviewer 1, Q2}} then predicts the target state, plans a coarse-to-fine interception trajectory, and executes grasping. If the uncertainty of the target state becomes too high, the active state-regulation module triggers a reset behavior.

\begin{figure*}[!t]

\includegraphics[width=\textwidth]{figures/fig1_rev.pdf}
\caption{Overall framework of the proposed closed-loop perception, geometric modeling, and control system. RGB-D frames are first processed through instance segmentation (MSAM-Net) for mask refinement. The resulting point clouds undergo geometric consistency filtering (PX3C) and temporal stabilization (CAOS) to produce a reliable 3D representation. State estimation uses a Kalman-filter-based spatiotemporal approach, followed by two-stage motion planning in relative velocity space. \revadd{Active state regulation relocates unstable targets to restore observability before re-estimation and grasp planning.} \reviewnote{\mbox{Reviewer 1, Q2}; \mbox{Reviewer 3, Q5}}}
\label{fig:overview}
\end{figure*}

The central design principle is to avoid irreversible error propagation. A segmentation error can create 3D outliers, a distorted OBB can produce an incorrect grasp pose, and an inaccurate pose can further cause poor placement. Therefore, each stage is designed to evaluate and refine the information passed to the next stage. The framework also closes the loop at the physical level: when passive perception is insufficient, the robot actively changes the state of the baggage to recover observability.

\subsection{Task Definition}
Let $\mathcal{I}_{t}=(I_{t}^{\text{rgb}},I_{t}^{d})$ denote the RGB-D observation at time $t$. The system estimates an object state
\begin{equation}
\boldsymbol{b}_{t}=\{\boldsymbol{p}_{t},\boldsymbol{R}_{t},\boldsymbol{s}_{t}\},
\end{equation}
where $\boldsymbol{p}_{t}$, $\boldsymbol{R}_{t}$, and $\boldsymbol{s}_{t}$ denote the centroid, orientation, and size of the target baggage, respectively. Given the current robot end-effector state $\boldsymbol{x}^{\text{EE}}_{t}$ and the predicted target state $\widehat{\boldsymbol{b}}_{t+\Delta}$, the objective is to generate a grasp trajectory that reaches \revadd{a feasible grasp pose for the hybrid end-effector} \reviewnote{\mbox{Reviewer 1, Q3}} with bounded position and yaw errors. In the experiments, precision success requires a position error below \revadd{2~$\mathrm{cm}$} \reviewnote{\mbox{Reviewer 2, Q5}} and a yaw error below $5^{\circ}$.
